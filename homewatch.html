Homewatch

A network notebook for keeping track of the devices around you.

Explore the interactive demo ↗ Download experimental desktop for Windows ↓

Experimental and unsigned: This 64-bit desktop build has not been fully validated; Windows may display a security warning. It requires Microsoft Edge WebView2 Evergreen Runtime and .NET Framework 4.6.2 or later. Before extracting, verify that you trust the ZIP’s source. Right-click the downloaded ZIP, choose Properties, and if an Unblock checkbox appears, select it and click Apply. Then extract the entire ZIP, keep the included folder together, and run HomewatchDesktop.exe. If you already extracted a blocked ZIP, unblock the trusted ZIP and extract it again into a new folder.

Native backup export/import dialogs and navigation remain unverified. The desktop app uses a separate WebView2 profile; existing browser data does not transfer automatically. If migrating, keep the original data and carefully verify any export and import before deleting anything. Backups are unencrypted.

THE IDEA

A practical inventory, not a security product. Homewatch pairs simple device notes with optional, user-initiated discovery in the local app.

Public demo: fictional devices and a simulated scan only.

01 / THE WORKFLOW

A notebook, not a monitor.

The local application supports adding, editing, searching and deleting devices, marking them known or unfamiliar, reviewing change history and Statistics, and exporting or importing a JSON backup. Its optional discovery is started deliberately by the user on an authorized network.

The public demo illustrates search, a simulated discovery, and reset. It does not connect to a local helper or access your network, and its sample data resets on refresh.

02 / UNDER THE HOOD

Built to stay local.

The original app uses HTML, CSS and JavaScript with browser-local storage. The bundled local helper on Windows lists private IPv4 subnets and uses ICMP and the local ARP cache for discovery; it does not scan ports. Backups are unencrypted JSON.

The public demo is a separate static HTML, CSS and JavaScript experience. It contains no helper, inventory from the original app, or real scan functionality.

03 / LIMITATIONS

Context matters.

Discovery can miss devices that are asleep, isolated, firewalled, IPv6-only, or otherwise unresponsive. A missing device is not necessarily offline; MAC addresses do not prove identity. This is not continuous monitoring, a vulnerability scanner, or a security product.

Only scan networks you own or have permission to scan. Browser data and unencrypted backups can contain sensitive details.
